# Ambient audio (local only)

## Setup

1. Put your tracks under `public/audio/` (see filenames in `playlist.json`).
2. Edit `playlist.json` if you rename or reorder tracks.
3. Toggle **Music** in the top-right HUD.

A convenience script (from repo root) if you keep downloads elsewhere:

```bash
# example — adjust source paths
cp "/path/to/track.mp3" public/audio/01-main-theme-piano.mp3
```

## Copyright

**Do not commit or deploy copyrighted commercial OST files.**  
`*.mp3` under this folder is gitignored. `playlist.json` and this README are safe to commit.

Use only audio you have the right to play locally (personal copies, licensed covers, or royalty-free ambience).
